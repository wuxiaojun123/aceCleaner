# 网络测速页面设计

依据：`activity_network_test.xml`、`NetworkTestActivity.kt`、`SpeedTestGaugeView.kt`。参考项目现有橙色 #FF6B2C，不绑定额外设计系统。

任务：保留进入自动测速、延迟→下载→上传、实时速度、成功反馈、重测、断网与失败反馈。仅产出设计原型，未改动 Android 业务代码。示例数值为模拟数据，不进行实际网络测速。

设计：暖白背景配低饱和浅橙；用细圆环表示整个流程的进度（并非速度刻度）；指标加文字标签，数字与单位分离；完成后显示勾选及文案，三个结果继续保留。底部固定按钮，窄屏内容可以滚动。

交互：首次进入自动演示，可重测。桌面审阅工具可切换橙/蓝紫/青绿配色，查看待测、下载、上传、完成、失败、断网。返回按钮返回原型入口，可重新进入并自动演示。

验证清单：自动测速流程、重复点击锁定、完成/重测、失败/断网、返回、窄屏、减少动画偏好。

预览：`python3 -m http.server 4311 --directory designs`，打开 http://localhost:4311/network-speed/ 。
